## 2. 项目简介

MoonBit 已经有几套 S3 客户端，但还没有能直接部署的 S3 服务端。MoonBit 应用想存头像、文档或构建产物，仍然得接 AWS、MinIO 或其他外部服务；本地开发和 CI 也不够方便。

本项目用 MoonBit 写一个可以长期使用的小型对象存储，不只交几个接口，而是交付一套完整工具：

- 服务端：建桶、上传、下载、列文件、分段上传和临时链接；
- 管理端：Web 控制台和命令行工具，能看文件、查用量、做备份和排错；
- 工程配套：启动示例、兼容性测试、压测脚本、发布包和完整文档。

它不是要替代 MinIO，而是补上 MoonBit 生态里“自己可控、开箱能用”的文件存储底座。第一版面向单机、私有化和边缘场景，现有 S3 工具和 SDK 可以直接连接，调用方不需要是 MoonBit 程序。

## 3. 预期使用场景

### 场景一：给 MoonBit Web 应用存附件

应用把用户上传的头像、文档和图片存到本地服务，不依赖外部云存储；需要时生成短期有效的下载或上传链接。控制台可以直接看桶、搜文件、复制链接和恢复旧版本。验收时，`awscli` 能完成建桶、上传、列文件和临时链接，浏览器跨域上传正常，签名错误和不存在的文件会返回正确错误。

### 场景二：CI 里当 S3 测试替身

测试时在临时目录启动服务，用随机端口和临时密钥跑现有 S3 客户端测试，结束后直接清理，不需要 Docker、MinIO 或外网。验收要求：可以反复启停，常用操作都有自动化测试，写入中断不会留下坏文件，异常退出后重启能继续处理未完成的分段上传。

### 场景三：私有化部署和边缘存储

团队在本地机房或边缘节点存备份、静态资源和构建产物。原来的 S3 客户端不用改代码，大文件可以分段上传，下载支持断点续传，重要桶可以保留历史版本。验收时，`awscli` 和 MinIO `mc` 能完成完整往返，100 MiB 文件能分段上传并按区间下载，备份和恢复命令能保留对象元数据。

### 场景四：MoonBit S3 客户端的互操作测试场

现有 MoonBit S3 客户端可以拿本项目做本地测试服务，不再依赖真实云账号。项目会维护兼容矩阵和可复现的测试数据，客户端作者能快速定位签名、编码、分页和错误处理问题。这会让服务端和客户端互相促进，而不是各做各的。

## 4. 交付物与边界

第一版只做“单机、本地磁盘、path-style”的常用能力，不追求完整 S3。兼容性参考 AWS S3 API，外部验证使用 AWS CLI、MinIO `mc` 和 Ceph `s3-tests` 的一部分。

### 本期交付

- **可执行服务**：一个 native 服务进程，支持配置文件、环境变量、优雅退出、健康检查和示例 Dockerfile；
- **S3 核心能力**：建桶、删桶、列桶；上传、下载、查看信息、删除文件；按前缀列文件、分页和分隔符；区间下载和条件请求；大文件分段上传；临时的上传/下载链接；
- **常用扩展**：桶级公开读/私有切换、CORS、基础版本控制和上传/删除事件通知；
- **管理工具**：Web 控制台、管理命令行、备份/恢复和存储检查命令；
- **运维能力**：结构化日志、基础指标、启动自检、写入失败提示和异常恢复说明；
- **验证与发布**：单元测试、接口测试、崩溃恢复测试、安全负向测试、`awscli`/`mc` 互通测试、`s3-tests` 子集、README、演示脚本和 GitHub Release 包。

### 本期不做

多机、纠删码、跨区域复制、完整 IAM/ACL、Object Lock、完整生命周期、服务端加密、计费和多租户管理界面。TLS 交给反向代理。

### 验收底线

`scripts/release_check.sh` 能一条命令跑完格式检查、编译、测试、客户端互通和外部兼容测试；100 MiB 文件往返不损坏；写入中断和服务重启后数据仍可读；所有失败请求返回稳定、可解释的错误，不把未完成的操作当成成功。

## 5. 拟实现的核心功能

- **请求处理**：接收 S3 风格的 HTTP 请求，识别桶、文件和操作类型，统一返回标准错误。
- **身份校验**：支持 AWS 常用的签名方式和临时链接，签名不对就拒绝；控制台使用独立的管理员口令。
- **文件读写**：保留对象元数据，支持区间下载、条件请求、ETag 和内容校验；上传先写临时文件，成功后再替换。
- **文件列表**：支持前缀、分页和分隔符，结果顺序稳定，空目录和特殊字符不会出错。
- **分段上传**：支持创建、上传分片、查询、完成和取消；清理过期分片，重启后继续未完成任务。
- **桶级功能**：CORS、基础版本控制、公开读/私有切换，以及上传/删除后的 JSON 事件回调。
- **管理与运维**：控制台完成常用操作，命令行负责备份、恢复、清理和诊断；提供健康检查和基础指标。
- **兼容性测试**：维护 AWS CLI、MinIO `mc` 和 Ceph `s3-tests` 的通过矩阵，单独记录不支持项，不把“没测过”写成“已支持”。

实现优先复用 MoonBit 现有的 HTTP、XML、哈希和序列化库，不自己重造底层网络栈。计划六周完成主体：第一周跑通建桶、上传、下载和错误返回；第二周做签名、列文件、区间下载和条件请求；第三周做分段上传与崩溃恢复；第四周做 CORS、版本控制、事件通知和备份工具；第五周做控制台、命令行和运维端点；第六周做外部互通、负向测试、文档和发布。剩余时间用于兼容性打磨和真实场景试用。

## 6. 是否为原创项目

本项目为原创实现，不移植 MinIO，也不复制现有 S3 服务端源码，更不是给现成服务端套一层 MoonBit 外壳。实现依据公开的 AWS S3 API 文档；Ceph `s3-tests`（MIT）只作为外部一致性测试；`mldong/moon-s3`（Apache-2.0）只用来对照公开的签名测试向量，不复制源码。

去重说明：目前 MoonBit 里的 S3 项目都是客户端或存储抽象，例如 `mldong/moon-s3`、`mizchi/s3`、`kaashyapan/s3`、`sos`、`bit_objstore`，没有可部署的 S3 服务端。本项目补的是服务端这一层，并额外提供控制台、管理工具和互操作测试，和现有客户端互补。核心服务、控制台后端和管理命令行均以 MoonBit 为主要实现语言。开发过程中使用 AI 辅助，项目自身采用 Apache-2.0。
